# 大气数据采集与运维支撑工具

## 项目简介
基于Python实现公开气象数据的自动化采集、清洗、分析与可视化，完整覆盖数据采集-ETL处理-数据分析-可视化全流程，模拟运维场景下的数据监控、日志清洗与报表输出流程，锻炼自动化脚本开发与问题排查能力。

## 技术栈
Python、Requests、BeautifulSoup、Pandas、Matplotlib/Pyecharts

## 项目流程
1. 数据采集：编写Python爬虫脚本，定时定向爬取公开气象网站数据，通过设置请求头和随机访问间隔避免限制，模拟运维定时任务场景。
2. 数据清洗：对原始数据进行去重、缺失值填充、异常数据剔除、字段格式统一，处理数据异常与格式问题，保障数据质量。
3. 数据分析：按时间维度做数据统计，计算日均值、波动、极值等指标，分析数据变化趋势，支撑运维监控分析需求。
4. 数据可视化：使用Matplotlib/Pyecharts生成折线图/热力图，直观展示数据规律，便于快速监控数据变化，输出运维报表。

## 项目亮点
• 全程爬取公开免费气象数据，无隐私/违规采集风险，合规稳定。
• 完整实现从网页数据到可视化报表的自动化流转，熟悉数据ETL与运维报表输出全流程。
• 处理了反爬限制、数据空值、格式异常等实际问题，具备数据异常排查与问题解决能力。
