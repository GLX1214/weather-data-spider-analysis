# 天气数据爬取、清洗与可视化项目

## 项目简介
基于Python实现公开气象数据的自动化采集、清洗、分析与可视化，完整覆盖**数据采集-ETL处理-数据分析-可视化**全流程，与数据开发/爬虫岗位的日常工作流程高度匹配。

## 技术栈
Python、Requests、BeautifulSoup、Pandas、Matplotlib/Pyecharts

## 项目流程
1.  **数据采集**：定向爬取公开气象网站的日期、气温、湿度等公开数据，通过设置请求头和随机访问间隔避免被限制，保证采集稳定合规。
2.  **数据清洗**：对原始数据进行去重、缺失值填充、异常数据剔除、字段格式统一，将杂乱数据转为结构化可用数据。
3.  **数据分析**：按时间维度做统计，计算日均温、温度波动、极值等指标，分析天气变化趋势。
4.  **数据可视化**：使用Matplotlib/Pyecharts生成折线图/热力图，直观展示数据规律。

## 项目亮点
- 全程爬取公开免费气象数据，无隐私/违规采集风险。
- 完整实现从网页数据到可视化报表的自动化流转，熟悉数据ETL全流程。
- 处理了反爬限制、数据空值、格式异常等实际问题，具备问题排查与解决能力。

## 运行说明
1.  安装依赖：`pip install requests pandas matplotlib pyecharts`
2.  依次运行爬虫脚本、数据清洗脚本、分析与可视化脚本即可。
